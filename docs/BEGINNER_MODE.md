# Beginner-First Project Standard

Every project in this repository must be understandable to someone with little or no technical experience.

## Required format

**What we're building → What you need → Before we start → Step 1 → expected result → troubleshooting → test → next step → final checklist.**

Use one action at a time, exact commands/wiring when possible, and explain unfamiliar terms.

## Debugging

For every failure, explain: what happened, why it likely happened, one safe first fix, and how to verify the fix. Never tell a beginner only to check logs.

## Hardware

State exact board/component, voltage, ground, pins, wiring, polarity where relevant, and a no-power checkpoint before powering a circuit.

## Software and AI

List prerequisites and versions, verify dependencies separately, explain where processing happens, and keep generated code review-first rather than silently executing it.

## Security

Never commit passwords, API keys, tokens, or private credentials.
