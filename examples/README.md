# Examples

Try these commands:

```bash
python -m cli.main translate "print hello world" --target python
python -m cli.main translate "create a variable called speed equal to 100" --target rust
python -m cli.main translate "if temperature is greater than 30 print hot" --target javascript
python -m cli.main translate "repeat 3 times print hello" --target c
python -m cli.main translate "create table users with id integer, name varchar(100)" --target sql
```
